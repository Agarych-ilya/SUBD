# Обновление программы СУБД — 05.11.2026

## 1. Общий фильтр во всех окнах

Кнопка **«Общий фильтр»** расположена в верхней части главного окна.

- Единственная настройка географии (округ, субъект РФ, город, вуз) и рубрики ГРНТИ распространяется на вкладки **НИР, Финансирование, Справочник вузов, ГРНТИ** и четыре аналитических отчёта.
- Если выбрать **вуз**, будут автоматически заполнены соответствующие **город, субъект и округ**.
- Если выбрать **город**, заполнятся однозначно определённые **субъект и округ**. Если город встречается в нескольких субъектах, программа не делает ложный выбор: неоднозначные поля остаются «Все».
- Если выбрать **субъект**, автоматически определяется однозначный **округ**.
- Списки в обратную сторону ограничиваются выбранными верхними уровнями. При смене верхнего уровня прежние несовместимые нижние значения сбрасываются.
- **«Отмена»** закрывает диалог без изменения общего фильтра. **«Применить»** обновляет все таблицы/отчёты. **«Сбросить всё»** очищает черновик. Кнопка «Сбросить фильтр» сверху очищает применённый фильтр сразу.
- Поиск остаётся **отдельным для текущей таблицы**: он зависит от её столбцов и применяется дополнительно к общему фильтру.

## 2. Поиск

С нижних панелей таблиц удалены кнопки «Поиск» и повторяющиеся «Фильтр». Одна кнопка **🔍 Поиск** теперь расположена сверху над вкладками. Она открывает поиск по колонкам текущей таблицы.

## 3. Журнал изменений

Меню **«Опции» → «Журнал изменений»**.

- **Добавление** помечается **синим**, **удаление — красным**, изменения остальных полей — нейтральным цветом.
- Вместо сырого JSON отображается таблица с русскими названиями полей и двумя колонками **«До» / «После»**; изменившиеся значения выделены.
- Выделите строку **«Удалено»** и нажмите **«Восстановить удалённую НИР»**, чтобы вернуть исходный ID, номер, название, ГРНТИ, руководителя, финансирование и остальные поля.
- Выделите строку **«Добавлено»** и нажмите **«Удалить добавленную НИР»**, чтобы откатить создание.
- Перед отменой требуется подтверждение. Если после выбранного действия запись меняли, либо возникает конфликт уникального номера/ID, **отмена запрещается**, а база остаётся неизменной.
- Каждая успешная отмена сама создаёт запись в журнале с указанием номера исходной операции.

## 4. Полная выгрузка НИР в Excel

В верхней панели и меню **«Данные»** есть действие **«Выгрузить все НИР в Excel»**.

- Сохраняет **все записи НИР из базы**, независимо от применённых фильтров и поискового текста.
- Столбцы: ID, код вуза, регистрационный номер, характер НИР, краткий вуз, ФИО и должность руководителя, ГРНТИ, название, плановое финансирование, округ, субъект, город.
- Регистрационные номера (`001`, `07`) и коды ГРНТИ остаются **текстовыми**, без потери ведущих нулей. Установлены автофильтр, закрепление заголовков, денежный формат и читаемые ширины.
- Существующий экспорт аналитических отчётов **сохраняется** и учитывает общий фильтр (в том числе рубрику).

## Дополнительные изменения интерфейса (05.11.2026)

- Вместо кнопки запуска отдельного окна поиска добавлена строка поиска прямо над таблицами: выбор поля + ввод текста. Поиск применяется по мере ввода и не сбрасывает общий фильтр. При переключении вкладок поле и строка меняются в соответствии с текущей таблицей.
- Кнопка «Общий фильтр» переименована в «Фильтр»; «Сбросить фильтр» сгруппирована рядом.
- Отдельная нижняя кнопка сортировки по ключу убрана. Сортировка НИР теперь в выпадающем списке сверху (по вузу ↑/↓, рег. номеру, названию).
- Имена всех новых Excel-выгрузок по умолчанию содержат текущую дату `ГГГГ-ММ-ДД`; при ручном имени дата добавляется автоматически.
- Файл `test_export_filename.py` проверяет корректные названия. Существующие GUI-тесты обновлены под строковый поиск.
