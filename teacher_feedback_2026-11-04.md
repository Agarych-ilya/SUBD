# Доработка по схеме от 04.11.2026

В доступной фотографии явно выделены общее количество, суммы планового и фактического финансирования, процент исполнения, группировка/территориальный разрез, проверка и обновление/сохранение итогов.

Реализованы: финансовый блок итогов во вкладке «Финансирование вузов», новая сводная таблица с группировками, проверка совпадения финансирования с НИР по вузам, экспорт Excel. В ранее реализованные НИР, справочники и остальные отчёты не внесены изменения, требующие миграции данных.

Не предполагается, что неразборчивые рукописные пункты и вся 36-минутная аудиозапись дословно воспроизведены; запись требуется прослушать для финальной сверки дополнительных требований. Это рабочая реализация однозначной финансовой части, а не заверение, что все замечания преподавателя учтены.

## Контроль

```
python -m unittest -v test_financial_report
```

На исходной базе ожидается 400 НИР, план 360 917 220 ₽. Факт 0 ₽, если его ранее не вводили. Пересчёт не меняет факт, введённый пользователем.
